# Claim scope

The model is recursive with one common endogenous order, and its domain is a finite set explicitly provided with the input. Outcomes under different interventions in one event share the same exogenous draw. The outer formula is a set of weak basic or linear inequalities, all of which must hold.

The two-variable claim permits domains that grow with the input. With the domain size also fixed, the problem already falls under the original combined-parameter algorithm. The one-variable LP claim uses the conjunction-only outer syntax. Polynomial terms, compact marginalization and arbitrary Boolean combinations of comparisons are outside its scope.
