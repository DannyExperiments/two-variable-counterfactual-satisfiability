# Q891: Two variables suffice for NP-complete counterfactual satisfiability

## Result

**Theorem.** The linear and even basic comparative counterfactual satisfiability problems are NP-complete for n=2, polynomial time for n=1, and in XP for n alone if and only if P=NP. Two-variable hardness holds for one probability-one Boolean formula using only atoms of the form “Y=1 under setting X=i”; the variables may even be supplied in the order X before Y. There is no term multiplication or compact summation.

## Hardness

Take any Boolean CNF φ with variables z₁,…,z_m. Give both endogenous variables X,Y a common explicitly listed domain containing m distinct input symbols i₁,…,i_m and two distinct output symbols 0,1. Let E_j be the counterfactual atom [X=i_j](Y=1). Form F by replacing every positive z_j by E_j and every negative z_j by its negation in φ. Disjunction can be expressed by negation and conjunction. Require Pr(F)≥Pr(T) with T a tautological event (for example ¬(E₁ ∧ ¬E₁)); the no-variable case is trivial. This is one basic comparison of two probability terms in the exact source grammar.

If a recursive SCM satisfies the comparison, there is a latent draw in its support making F true, since Pr(F)=1. In that draw the truth values of the individual E_j give a Boolean assignment. Different occurrences of E_j evaluate in the same fixed latent draw with the same intervened equation, so this assignment satisfies φ. This implication does not assume any particular order in the proposed model or require Y to use only 0 and 1: every atom E_j always has one truth value.

Conversely a satisfying Boolean assignment is realized by a deterministic SCM with X constant, Y=f(X), f(i_j) equal to the assigned bit, and f arbitrary on the two unused symbols. It has the same recursive order X,Y at every draw and no exogenous randomness. Thus the formula is satisfiable exactly when φ is. The transformation is polynomial and uses only two variables. If a 3-coloring presentation is preferred, use three output symbols, impose one probability-one color-disjunction per vertex and a probability-zero cross-world conjunction for each edge/color; the same one-draw argument gives exactly proper colorings.

## Upper bounds and the sharp slice boundary

Given n, d and an order, by [source Lemma 5.2, p. 8](https://raw.githubusercontent.com/mlresearch/v306/main/assets/ganian26a/ganian26a.pdf#page=8), each latent draw can be represented by one deterministic table per endogenous variable: the j-th one maps D^(j−1) to D. This is also immediate by fixing the exogenous input and recording its functions. A draw is represented by at most n d^(n−1) entries; conversely a mixture of tables with the same order defines a valid single finite latent variable.

Let M be the number of distinct event expressions occurring inside probabilities of the input, and map each deterministic table tuple to its M-dimensional Boolean event vector, computed by simulating each explicitly specified intervention in order. A satisfying real vector of probabilities is in the convex hull of these Boolean vectors for some order. Carathéodory's theorem represents it by at most M+1 tuples. With those tuples fixed, the input inequalities are rational linear constraints in the mixture weights; if feasible, they admit polynomial-bit rational weights by taking a vertex of the bounded feasible polytope (standard determinant bounds). For any allowed strict inequalities, introduce a shared bounded positive slack, maximize it and take a vertex with positive slack. Thus for fixed n guess the order, at most M+1 explicit tuples and their rational weights and verify them in polynomial time. No enumeration of every possible tuple is required. When n=1 the observational value is the only free entry, and nonempty interventions fix the sole variable; an explicit LP over the d possible observational values suffices.

For uniform XP under P=NP, use the same verifier on a padded input: include enough unary padding for the table description and verification bound, computable in time |I|^{O(n)}. The padded language is in NP via the preceding witnesses and a uniform length check; under P=NP it has a uniform polynomial-time decider, giving an XP algorithm in the unpadded parameter. Conversely XP would already solve the directly reduced CNF instances in polynomial time at n=2. Thus the condition is precisely P=NP.
