# Q891 primary sources and exact scope

**Verdict, 27 November 2026.** High confidence that the proof addresses the fixed-variable question in the ICML paper. This bounded primary-source check did not locate an earlier two-endogenous-variable hardness result for the same explicitly supplied domain and conjunction-of-comparisons syntax. Earlier results give the response-table construction, small model techniques and unrestricted hardness. Priority has not been established.

## Pinned question and grammar

Robert Ganian, Marlene Gründel and Simon Wietheger, *Gateways to Tractability for Satisfiability in Pearl’s Causal Hierarchy*, [ICML 2026, PMLR 306, pp. 32958–32968](https://proceedings.mlr.press/v306/ganian26a.html), [§6 third item, PDF p. 9](https://raw.githubusercontent.com/mlresearch/v306/main/assets/ganian26a/ganian26a.pdf#page=9), ask whether linear counterfactual satisfiability is in XP in the number n of endogenous variables alone. The [author arXiv version history](https://arxiv.org/abs/2511.08091) lists a January 2026 revision. The question and numbering here refer to the camera-ready PMLR paper.

[§§2–3, PDF pp. 4–5](https://raw.githubusercontent.com/mlresearch/v306/main/assets/ganian26a/ganian26a.pdf#page=4) specify a common domain D supplied as a set of d values. Different interventions may be combined by Boolean operations *inside* an event, with one common exogenous draw. At the outer level §3 explicitly restricts the input to a set of inequalities, in contrast to arbitrary Boolean combinations of inequalities. The defined comparison uses ≤. Basic comparisons have one probability term per side; linear comparisons allow sums. One-variable polynomial tractability in this release refers to precisely that outer conjunction of weak comparisons. The hardness reduction uses one comparison and an arbitrarily large finite explicitly listed domain with two distinct output symbols.

## Earlier results

- [Ganian, Gründel and Wietheger, Lemma 5.2 and Theorem 5.3, PDF p. 8](https://raw.githubusercontent.com/mlresearch/v306/main/assets/ganian26a/ganian26a.pdf#page=8) reduce a model to a mixture of recursive deterministic response-table tuples with one common order and give an LP for each order over all tuples. Their fixed-parameter bound uses n+d jointly. It can coexist with NP-completeness at n=2 when d grows. This paper uses their table representation and sparsifies mixtures by their vectors of input-event outcomes, applying ordinary Carathéodory and rational polytope vertex bounds.
- [Joseph Y. Halpern, *Axiomatizing Causal Reasoning*, JAIR 12 (2000), pp. 317–337, Theorem 4.4 and Appendix A](https://arxiv.org/abs/cs/0005030) proves deterministic recursive causal satisfiability NP-complete for an input finite signature. In its unrestricted Boolean syntax proof the signature has one binary endogenous variable per proposition, and an alternative proof for the narrower Galles–Pearl syntax adds clause variables. The present construction instead places separate Boolean coordinates at different input values of one response table.
- [Milan Mossé, Duligur Ibeling and Thomas Icard, *Is Causal Reasoning Harder Than Probabilistic Reasoning?*, Rev. Symb. Log. 17(1), 106–131 (2024)](https://doi.org/10.1017/S1755020322000211) establish unrestricted satisfiability complexity across the causal hierarchy. [Author text, §4.2](https://arxiv.org/html/2111.13936#S4.SS2) obtains the ordinary lower bounds from the probabilistic sublanguage. The endogenous-variable count in those reductions is unrestricted.
- [Bläser, Dörfler, Liśkiewicz and van der Zander, ICALP 2025](https://doi.org/10.4230/LIPIcs.ICALP.2025.144) study supplied causal graph structure and polynomial-size model restrictions, including the effects of compact marginalization. [Dörfler et al., arXiv:2405.07373](https://arxiv.org/abs/2405.07373) give unrestricted basic/linear counterfactual complexity with compact marginalization. The source problem here has no compact marginalization and counts named endogenous variables in a shared domain of variable size.

The explicit two-variable reduction preserves an order X before Y if supplied and has a deterministic satisfying witness for every satisfiable input CNF. The hardness argument remains sound with arbitrary allowed exogenous mixtures. An input with one variable has only d relevant observational response types, making the source's inequalities an LP. The case with d fixed already falls under the source's combined parameter result. Search included follow-ups to the exact §6 question, fixed endogenous counts, variable domains and earlier small-model or prescribed-graph results.
