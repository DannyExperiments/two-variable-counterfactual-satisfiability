# Offline response-cube explorer

Extract these files into one directory and open index.html. Select the three truth values for the response table, then rotate the cube. Each cube vertex records whether Y equals 1 at the three designated interventions on X. The outlined vertex is your selected response. Green vertices satisfy all three clauses. Use the clause readout to see what succeeds or fails.

Both files are self-contained. The proof and a tabular explanation are in the release repository.
